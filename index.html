PIDSMaker¶

Build, benchmark and extend graph-based intrusion detection systems.

State-of-the-art provenance and network IDSs, their datasets and one modular pipeline, all open source.

Get started Quickstart GitHub Discord

Runs on Linux (GPU or CPU) macOS (Apple Silicon)

Up and running in two commands¶

From v5.0.0, PIDSMaker needs no database server or Docker: datasets are downloaded from Hugging Face on first use.

pip install pidsmaker
pidsmaker orthrus CADETS_E3

Requires Python 3.9–3.11 · Installation guide

17intrusion detection systems
17datasets
7configurable pipeline stages
15+pretrained encoders

One framework, two views¶

  • Provenance

    System events inside each host: processes, files and netflows. Provenance-based IDSs (Velox, Orthrus, Kairos, MAGIC...) on DARPA TC, OpTC, ATLASv2 and CARBANAKv2, detecting the entities of an attack.

    Provenance graphs

  • Network

    Authentications and flows between hosts. Network IDSs (Euler, Argus, Jbeil, LARES...) on LANL and the network flows of OpTC, detecting the malicious events of lateral movement.

    Network graphs

Both go through the same seven stages and share the same components, so most systems run on either kind of data, and a new idea can be tested on both.

Why PIDSMaker?¶

Papers at top security venues often evaluate on the same datasets, but each uses its own labels and its own implementation of the baselines, so their results can't be compared fairly. PIDSMaker gives the community one framework, maintained in the open, that fixes this.

  • Fair benchmarking: state-of-the-art baselines evaluated with the same datasets, labels and reference implementations.
  • Modular components: the components of published systems, extracted into a testbed where you mix and match them to discover better variants.
  • Shared code: a central place where authors contribute their systems, so new work can be benchmarked reproducibly.

Next steps¶

Run any system on a provenance or a network dataset, by name:

pidsmaker velox CADETS_E3          # a provenance IDS
pidsmaker euler LANL               # a network IDS
pidsmaker kairos THEIA_E3 --wandb  # logged to Weights & Biases

All the datasets are Parquet files in the Hugging Face repository pidsmaker/datasets, from 0.16 GB (ATLASV2_EDR) to 74 GB (TRACE_E5), 178 GB in total. A run downloads its dataset when it is missing, or you can download datasets ahead of time:

pidsmaker download CADETS_E3 LANL  # some datasets
pidsmaker download --list          # all the datasets and their sizes

Runs on Linux, ideally with an NVIDIA GPU, for all datasets, and on macOS (Apple Silicon), on CPU, for most datasets: 32 GB of RAM is ideal (details).

Override any argument from the CLI, or write a new YAML config that inherits from an existing system.

pidsmaker orthrus CADETS_E3 \
  --featurization.used_method=doc2vec \
  --training.encoder.used_methods=tgn,sage \
  --training.encoder.sage.num_layers=3
